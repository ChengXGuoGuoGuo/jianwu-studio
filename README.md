# 见物 STUDIO

一个可独立对外经营的商品视觉服务项目。

## 一句话

保留产品主体，重做场景、光线和氛围，把普通产品照片做成可用于电商上架的商品图。

## 本地预览

直接打开 `index.html`，或在目录内启动静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 商业模式

1. 用 39 元首单降低第一次尝试门槛。
2. 用 1:1 / 3:4 双尺寸、先小样和明确修改边界建立信任。
3. 单张成交后转 129 元三张套图和 299 元详情页。
4. 通过闲鱼承接明确购买意图，通过小红书展示过程和判断能力。
5. 所有作品先做无品牌样片，不冒充真实客户案例。

- 只统计平台已结算、扣除平台费用后的金额。

- 每单记录：来源、报价、成本、交付时长、修改次数、净利润。
