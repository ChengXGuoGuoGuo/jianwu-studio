# 第一笔收入冲刺

## 目标

7 天内完成 1 笔真实付费订单，不把“发布”当成结果。

## 已验证

- 闲鱼商品已审核通过并处于在售状态。
- 商品图片、价格、详情和无需邮寄设置已完成。
- 独立作品页已发布，所有下单按钮均指向闲鱼商品。
- 独立站 sitemap、robots.txt 和 IndexNow 验证文件已上线。
- IndexNow 已接受提交，搜索收录仍需等待。

## 今天必须完成

1. 记录商品首小时浏览、想要、私信和成交。
2. 检查闲鱼消息中是否出现该商品的新询单。
3. 把独立作品页发给 3 个真实电商卖家朋友，只问：会不会询价，为什么。
4. 记录真实反馈，不用虚假聊天或刷单制造数据。

## 接下来 6 天

### 第 2 天

- 搜索“AI商品图代做”“商品图代做”“电商场景主图”，记录是否已收录。
- 若闲鱼已产生询单，优先响应，不继续扩渠道。

### 第 3 天

- 对香氛、家居、配饰三个方向各补 1 张场景样片。
- 将新样片更新到独立站，不冒充客户案例。

### 第 4 天

- 检查独立站的 Google/Bing 收录状态。
- 根据问询或浏览数据判断是否需要调整标题和首图，不先降价。

### 第 5 天

- 把所有真实问题补进商品详情或独立站 FAQ。
- 复盘价格、效果、交期、信任四项阻力。

### 第 6 天

- 若仍无自然曝光，只优化现有商品，不重复发布同款。
- 若出现咨询但未成交，检查回复速度和报价边界。

### 第 7 天

- 统计浏览量、私信数、有效询单、报价数和成交数。
- 如果 0 询单：换标题和首图，不先降价。
- 如果询单多但不成交：检查信任、边界和价格表达。
- 如果成交 1 单：按交付手册完成，拿到真实好评后再扩量。

## 关键指标

| 指标 | 第一周目标 | 判断 |
| --- | ---: | --- |
| 有效曝光 | 100+ | 低于 30，先查搜索收录和分类 |
| 私信询单 | 2+ | 0 个，说明外部流量不足 |
| 有效报价 | 1+ | 询单多但不报价，原图或需求不匹配 |
| 成交 | 1+ | 首周先验证真实需求，不追求规模 |
| 交付时长 | ≤24h | 超时说明接单量或流程有问题 |

## 不能做的事

- 不刷单、不伪造聊天、不虚构客户评价。
- 不买所谓“爆款流量”或承诺收益的课程。
- 不用客户图做未授权案例。
- 不同时开太多平台导致回复超时。
- 不为了成交承诺做不到的细节一致。
- 不运营小红书，不重复发布同款商品。
